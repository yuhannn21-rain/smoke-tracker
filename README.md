# 控烟记录微信小程序

一个本机保存数据的微信小程序，用来记录每天抽烟数量、设置每日目标，并查看 7 天和 30 天趋势。

## 功能

- 今日快速记录一支烟
- 今日目标、剩余额度、超量状态
- 当天记录列表和误记删除
- 近 7 天 / 30 天统计、均值、超标天数、估算花费
- 每日目标、每包支数、每包价格、提醒偏好设置
- 本地保存，不登录，不上传数据

## 打开方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `E:\小程序`。
4. AppID 可继续使用测试号，也可替换成自己的小程序 AppID。

## 数据说明

数据保存在微信小程序本地存储中：

- `smoke_records`
- `user_settings`

清除本地数据会删除所有记录并恢复默认设置。
